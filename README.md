## 👩🏻‍💻 Acerca de mí

¡Hola! Soy **Natalia Alvarado**, actualmente estudio **Desarrollo de Software (Programador Analista)** en **Duoc UC, Chile**.

Mi enfoque principal es el **desarrollo de backend, la computación en la nube y DevSecOps**, con un gran interés en la **calidad del software**, la **mantenibilidad** y el **desarrollo seguro**.

Principalmente construyo aplicaciones con **Java** y **Spring Boot**, trabajando con **bases de datos**, **contenedores**, **canalizaciones de CI/CD** y plataformas en la nube como **AWS** y **Microsoft Azure**.

También tengo base en **frontend** y despliegue web, utilizando herramientas como **HTML, CSS, JavaScript, Bootstrap, TypeScript, React, Node.js, GitHub Pages y Cloudflare**.

Disfruto comprender los sistemas más allá de simplemente hacerlos funcionar: cómo se comportan, cómo fallan, cómo se pueden proteger y cómo se pueden mejorar.

> Me gustan mis compilaciones ecológicas, mis advertencias en cero y mis sistemas explicables.
